# 像素远征：遗忘的誓约 · The Forgotten Oath

一款带完整剧情、随机地图、记忆档案与巨龙终章的原创像素风 Roguelite 浏览器游戏。全部画面与动画均由 Canvas 程序绘制，未使用《元气骑士》的官方素材。

**线上游玩：** [打开《像素远征》](https://yanzhao1027.github.io/soul-knight/)

## 新版本内容

- **随机地牢**：前三层每层随机生成 9–10 个相连房间；主线、支线、藏宝房、记忆房、事件房与 Boss 房均可达。障碍物和场景细节使用独立地图种子生成。
- **地图种子**：游戏内小地图右上角展示 Seed。网页地址附上查询参数 ?seed=12345，可重复生成相同的地图布局。
- **完整剧情**：记忆房与主线通路绑定，随机地图不会跳过关键故事。支线房间包含额外线索；开场、每层和 Boss 战时加入原创像素画面与对白。
- **记忆档案**：按 M 或点击游戏左侧记忆按钮，查看已经发现的线索。记录保存在浏览器 localStorage 中，跨局保留。
- **巨龙终章**：完成三层探索后进入固定设计的龙眠王庭，挑战 3600 HP 巨龙，包含三阶段战斗、剧情转折和诅咒水晶。
- **调查结局**：击败巨龙后必须亲自调查衣裳和戒指，才能解锁最终记忆，而不是立刻弹出胜利界面。建议第一次玩时不要跳过剧情。
- **保留玩法**：激光炮、回旋镖、飞剑、随机圣物、连击倍率、三段近战、闪避与移动端虚拟按键。

## 操作说明

| 功能 | 操作 |
|---|---|
| 移动 | WASD / 方向键 |
| 进入新房间 | 清怪后直接走进发光门 |
| 瞄准、射击 | 鼠标 / 按住左键，或空格开火 |
| 三段近战连击 | J |
| 冲刺、震荡技能 | Shift、Q |
| 调查宝箱和线索、下楼 | E |
| 武器选择 | 1–6 / F / 鼠标滚轮 |
| 记忆档案 | M |
| 下一句剧情 | 点击「继续」或按 Enter、空格 |
| 暂停 | P / Esc |

触屏设备提供虚拟摇杆、射击、近战、闪避、技能与换枪按钮。

## Ubuntu 本地启动

无需 npm 安装或打包，运行 Python 静态服务器：

    cd ~/Projects/soul-knight-web
    python3 -m http.server 4173

然后在浏览器打开 localhost 的 4173 端口即可。地址栏加 ?seed=my-seed 可复现固定迷宫。

## 开发与验证

用 Node.js 运行无第三方依赖的单元测试：

    node --test tests/*.test.mjs

单元测试涵盖随机迷宫连通性、必经记忆、随机地形碰撞安全、Boss 血量、剧情顺序和记忆档案。另用 Ubuntu Chromium + Puppeteer 测试完整三层、第四章巨龙、三阶段剧情、结局调查、移动端和浏览器错误。

## VitePress 发布

将 HTML/CSS/JS/MJS 放入 VitePress 仓库的 public/soul-knight/ 目录，构建时自动复制到 .vitepress/dist/soul-knight/，沿用现有 GitHub Actions 发布。
