# 像素远征 · 全武器扩展版

一款原创 HTML5 Canvas 像素地牢射击游戏。美术、角色及程序为原创实现，没有引用《元气骑士》官方素材。

**在线游玩：** https://yanzhao1027.github.io/soul-knight/

## 三层地牢 / 每层五房间

- 清除当前房间的敌人，**朝门口走过去就自动切换房间**，不用按 E。
- 回廊北侧有可选藏宝房：打开宝箱可随机选择 **3 件圣物中的 1 件**，提升本局生命、护盾、伤害、攻速、移速等属性。
- 宝箱同时解锁本层指定新武器；击败守关者也可能解锁旧武器；可返回旧房间，已开的宝箱不会刷新。
- 三位独立守关者：**熔核巨像、霜镜法师、深渊守卫**。生命值分别为 **820、1460、2280**，是扩展前对应生命值的 4 倍。
- 对战特色：熔岩环状弹幕、冰霜扇形射击与瞬移、深渊齐射和召唤随从。

## 6 种武器

| 武器 | 特殊效果 | 来源 |
| --- | --- | --- |
| 游侠短铳 | 标准射击 | 初始 |
| 星火连发 | 快速连射 | 第一层守关者 |
| 破晓霰弹 | 散射打击 | 第二层守关者 |
| **棱镜激光炮** | 直线穿透多名敌人并清除路径上的敌弹 | 第一层藏宝房 |
| **回响回旋镖** | 投掷后返回，去程和回程可以分别命中 | 第二层藏宝房 |
| **御风飞剑** | 自动追踪敌人，击中后飞回 | 第三层藏宝房 |

按 1–6 切枪，F 或鼠标滚轮循环切枪。移动端有换枪键。

## 随机圣物

每层藏宝房三选一，可永久提升本局属性（跨楼层保留），共有 12 类：

生命之种（最大生命）、星辉护符（最大护盾）、猛攻徽记（伤害）、疾风长靴（移速）、迅捷扳机（攻速）、剑舞纹章（近战）、守望水晶（护盾恢复）、寻宝磁石（拾取范围）、羽翼斗篷（冲刺冷却）、奥术核心（技能冷却）、赤月勋章（击杀回血）、苍穹透镜（远程伤害）。

## 操作

| 行为 | 控制 |
| --- | --- |
| 移动、穿房间门 | WASD / 方向键，直接走入已开启的门 |
| 瞄准 / 射击 | 鼠标 / 按住左键或空格 |
| 三段近战连击 | 连续按 J |
| 闪避、震荡技能 | Shift / Q |
| 打开宝箱、进入下一层传送门 | E |
| 切换武器 | 1–6 / F / 鼠标滚轮 |
| 暂停 | P / Esc |

手机提供虚拟摇杆、射击、近战、闪避、技能、换枪按钮。

## Ubuntu 本地运行

在 Ubuntu 终端执行：

    cd ~/Projects/soul-knight-web
    python3 -m http.server 4173

浏览器打开 http://localhost:4173/。游戏无需 npm 安装、打包或后端服务。

运行 Node.js 单元测试：

    node --test tests/*.test.mjs

游戏使用原生 HTML/CSS/JavaScript、Canvas 2D。
放入 VitePress 仓库的 `public/soul-knight/` 会自动发布到 `/soul-knight/`，无需独立部署。
