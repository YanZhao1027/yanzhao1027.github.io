# 像素远征 · 连击版 (Pixel Dungeon Combo Edition)

一款原创 HTML5 像素风地牢射击游戏，受俯视角 Roguelite 启发。绘图、角色及代码均为原创，未使用《元气骑士》官方素材。

**在线体验：** https://yanzhao1027.github.io/soul-knight/

## 游戏内容

- **3 层 × 5 房间**：入口、回廊、可选藏宝支线、试炼区、守关房；清怪开门，支持重访，小地图显示探索进度。
- **三段斩击**：连续按 J 完成三段近战连招，第三段是范围旋刃斩。
- **击杀连击**：连续击杀可刷新 4.8 秒计时、积累伤害倍率和额外金币掉落；受到攻击会中断。
- **武器**：初始短铳、星火连发、破晓霰弹；支线宝箱提供武器与补给。
- **敌人**：史莱姆、蝙蝠、远程射手，以及三层守关者。
- **其他**：闪避、清弹范围技能、生命与护盾、金币、评分、手机触控操作。

## Ubuntu 启动

在终端执行：

    cd ~/Projects/soul-knight-web
    python3 -m http.server 4173

打开 http://127.0.0.1:4173/，无需安装依赖。

## 操作

| 功能 | 操作 |
| --- | --- |
| 移动 | WASD / 方向键 |
| 瞄准 / 射击 | 鼠标移动 / 按住左键，或空格 |
| 三段近战连击 | 连按 J，衔接时间 0.83 秒 |
| 闪避 | Shift |
| 范围技能 | Q |
| 开宝箱 / 穿门 / 下楼 | E |
| 换枪 | 1 / 2 |
| 暂停 | P / Esc |

移动端配有虚拟摇杆、射击、近战、闪避和技能按钮。推荐横屏游玩。

## 部署到 VitePress

纯静态文件直接放在 VitePress 仓库的 public/soul-knight/ 下，构建会复制到 .vitepress/dist/soul-knight/。
沿用原有 GitHub Actions 自动发布到 GitHub Pages，无需独立部署。

## 已做测试

使用 Ubuntu Chromium + Puppeteer 端到端验证：三段连击、击杀倍率及到期、锁门、支线宝箱、重访、三层通关、暂停、移动端。
